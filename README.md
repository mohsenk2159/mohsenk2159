## 🌟 Featured Project

### 🎧 [irpotify / MusicHub](https://github.com/Mohsenk2159/irpotify)
A modern, self-hosted private music streaming server and cross-platform player app inspired by Spotify.
- **Backend:** .NET 10 Web API, Entity Framework Core, PostgreSQL, FFmpeg audio transcoding.
- **Frontend:** Fast React & Vite SPA with custom Emerald/Dark UI, offline PWA support, and real-time playback.
- **DevOps:** Fully containerized with Docker Compose and production Caddy reverse proxy.
